Privacy Policy

Marigold Letters is a personal tool used only by its owner with the owner's own TikTok account.

  • What is accessed: a TikTok access token that lets the app upload videos to the owner's inbox (scope video.upload) and read basic profile info (user.info.basic).
  • What is stored: the OAuth refresh token, kept only as an encrypted secret in the owner's private GitHub Actions settings. No other personal data is collected.
  • Sharing: no data is sold, shared or sent to third parties, other than the video being uploaded to TikTok itself.
  • Deletion: the owner can revoke access at any time in TikTok under Settings → Security & permissions → Manage app permissions, and delete the stored secret in GitHub.
