# Marigold Letters: کانال تیک‌تاک خودکار (فاز ۱: تولید ویدیو)

هر روز یک ویدیوی ~۶۵ ثانیه‌ای اسلایدشو ساخته می‌شود: متن احساسی و اورجینال روی عکس‌های نرم، با موسیقی گرم.

**Gemini (متن اورجینال + انتخاب عکس برای هر اسلاید) → Pexels (عکس واقعی) → ffmpeg (مونتاژ) + مولد موسیقی داخلی**

همه‌چیز روی ردیف رایگان اجرا می‌شود. خروجی در Artifacts هر Run قرار می‌گیرد.

## هر قسمت چه چیزی دارد
- ۱۰ تا ۱۲ اسلاید؛ هر جمله با فید نرم و جدا ظاهر می‌شود (نه یک‌باره)، جمله‌ی hook با رنگ رز.
- زوم آرام (Ken Burns)، گرید رنگی گرم، درخشش ملایم، دانه‌ی خیلی سبک و کراس‌فید بین اسلایدها.
- موسیقی منحصربه‌فرد برای هر قسمت (تونالیته‌ی ماژور، پد گرم + نت‌های جعبه‌موزیکی + reverb)، بدون مشکل کپی‌رایت.
- طول ۶۲ تا ۶۸ ثانیه (بالای ۱ دقیقه).

## چرخش قالب و موضوع (برای اینکه ویدیوها شبیه هم نشوند)
قالب‌ها (`profiles.quotes.templates`): **نامه، نشانه‌ها، حقیقت‌های گرم، داستان کوچک**، به‌ترتیب می‌چرخند.
موضوع‌ها (`profiles.quotes.themes`): عشق، بعد از شکست، خودارزشمندی، صداقت و منش، احترام، هدف و رشد شغلی، دوستی، شکرگزاری.
موضوع تکراری در ۴ قسمت اخیر انتخاب نمی‌شود. هرکدام را می‌توانی در `config/settings.yaml` عوض کنی.
لحن و قوانین در `config/bible_quotes.md` است (ایده‌ی اصلی: **مشخص و احساسی، نه کلی‌گویی**).

## راه‌اندازی
1. ریپو را در GitHub push کن.
2. کلید رایگان Gemini: https://aistudio.google.com/apikey
3. کلید رایگان Pexels: https://www.pexels.com/api/
4. **Settings → Secrets and variables → Actions** این‌ها را اضافه کن:
   - `GEMINI_API_KEY`
   - `PEXELS_API_KEY`
5. **Actions → daily-episode → Run workflow** را بزن و ویدیو را از Artifacts دانلود کن.

## مهم
- **ذکر منبع عکس:** قوانین API پیکسلز می‌گوید به Pexels و (در حد امکان) عکاس‌ها اعتبار بده. کپشن آماده در `ep_XXX.json`
  (فیلد `caption`) خودش عبارت `Photos: Pexels` دارد و اسم عکاس‌ها در `photo_credits` است.
- **اصالت (مهم‌ترین ریسک):** تیک‌تاک محتوای کم‌ادیت و تکراری را از For You و درآمدزایی کنار می‌گذارد، و نیش نقل‌قول عاشقانه
  شلوغ است. تفاوت ما: متن کاملاً اورجینال با قوس احساسی، قالب‌های چرخشی، و برند ثابت. از هیچ نقل‌قول معروفی استفاده نکن.
- **موسیقی:** صدای تولیدی ما سبک و ساده است. برای دسترسی بیشتر، هنگام آپلود در اپ تیک‌تاک یک Sound ترند اضافه کن
  (در حالت draft/دستی)، یا ترک‌هایی که حقشان را داری در `assets/music/` بگذار (جای موسیقی تولیدی را می‌گیرند).
- **برچسب AI:** عکس‌ها واقعی‌اند ولی متن را AI نوشته. اگر در اپ گزینه‌ی «AI-generated content» هست و مطمئن نیستی، روشنش کن.
- **مدل‌های Gemini** در `config/settings.yaml` هستند؛ هر چند ماه با https://ai.google.dev/gemini-api/docs/pricing چک کن.
- در ردیف رایگان، گوگل می‌تواند از ورودی/خروجی برای بهبود مدل‌ها استفاده کند. داده‌ی خصوصی نفرست.
- ویدیو داخل ریپو commit نمی‌شود؛ فقط `state/episodes.json` (حافظه‌ی قسمت‌ها).

## پروفایل ترسناک (اختیاری)
`content: horror` در settings.yaml همان سریال ترسناک قبلی را فعال می‌کند (تصاویر AI با Cloudflare، آرک‌های ۳ قسمتی).
برایش `CLOUDFLARE_ACCOUNT_ID` و `CLOUDFLARE_API_TOKEN` لازم است.

## آپلود روی تیک‌تاک (فاز ۲)
ویدیو هر روز به‌صورت **draft** در Inbox تیک‌تاک خودت قرار می‌گیرد؛ تو با ۱ تپ (و اضافه‌کردن Sound ترند) منتشرش می‌کنی.
راه‌اندازی کامل (ساخت اپ، توکن، Secrets، عیب‌یابی) در **`SETUP_TIKTOK.md`** است.
بدون Secretهای TikTok، پایپ‌لاین مثل قبل فقط ویدیو را در Artifacts می‌گذارد.

> پست عمومی کاملاً خودکار (Direct Post) نیاز به audit تیک‌تاک دارد و تا آن موقع همه‌چیز خصوصی می‌شود؛ جزئیات در SETUP_TIKTOK.md.
